\section{Classical Statistical Model}
Up to this point, we have acquired many statistical tools, and it is now time to step back and look at the whole picture. First, we collect a set of data points $(x_i, y_i)$. We then select an appropriate statistical model for the data, typically a parameterized one, and find the optimal parameters. Finally, we validate the model and use it to make predictions at new data points. In this section, we will discuss several statistical models. The section is organized as follows:
\begin{enumerate}
    \item Regression
    \item Classification
    \item Trees and Weak Learners
    \item Cross-Validation
    \item Time Series
\end{enumerate}

\subsection{Regression}

\subsubsection{Fundamentals}
In general, we can define the ``loss'' of guessing $\hat{y}$ when the true value was is $y$ as
\[
\mathscr{L}(\hat{y}, y) = \mathscr{L}(f(\bx), y)
\]
We want to find $f(\cdot)$ so that $\mathscr{L}(f(\bx), y)$ is as small as possible. But the loss for a particular $f$ may depend on $\bx_{\mathrm{new}}$, since different $\bx_{\mathrm{new}}$ are associated with different distributions of $y_{\mathrm{new}}$. It follows that it doesn't make sense to minimize the loss --- instead we want to minimize the \emph{risk},
\[
\mathscr{L}(f) := \mathbb{E}\left[\mathscr{L}(f(\bx), y)\right] \qquad \text{(Risk)}.
\]
So we would like to find
\[
f^{\star}(\cdot) := \operatorname*{argmin}_{f} \mathscr{L}(f) = \operatorname*{argmin}_{f} \mathbb{E}\left[\mathscr{L}(f(\bx), y)\right].
\]

We'll consider square loss first:
\[
l(\bx, y) = \frac 1 2(y - f(\bx))^2 \quad \hat{\mathcal{L}}(f) = \frac{1}{N} \sum_{i=1}^N l(\bx_i,y_i).
\]
We cannot actually compute $f^*$, a general question is how to calculate the gap between $f^*$ and $\hat f$.
\[
0 \leq \mathscr{L}(\hat{f}) - \mathscr{L}(f^*)
= \underbrace{\mathscr{L}(\hat{f}) - \hat{\mathscr{L}}(\hat{f})}_{\text{Difficult term!}}
+ \underbrace{\hat{\mathscr{L}}(\hat{f}) - \hat{\mathscr{L}}(f^*)}_{\text{Negative term}}
+ \underbrace{\hat{\mathscr{L}}(f^*) - \mathscr{L}(f^*)}_{\text{LLN term}}.
\]
It is called generalization error and the term $\mathcal{L}(\hat f) - \hat{\mathcal{L}}(\hat f)$ can be bounded $\sup_{f} [\mathcal{L}(f) - \hat{\mathcal{L}}(f)]$, which will be discussed in the later sections.

We begin with linear regression model:
\[
y_n = \beta_1 x_{n1} + \beta_2 x_{n2} + \ldots + \beta_P x_{nP} + \varepsilon_n = \underbrace{\bx_n^\top \bbeta}_{f(\bx_n)} + \epsilon_n, \quad \text{For } n = 1, \ldots, N.
\]
where we use $N$ to denote the number of data and $P$ to denote the number of features.
To get the optimal estimator $\hat{\bbeta}$, we let
\[
0 = \frac{\partial}{\partial \bbeta} \mathcal{L}(\bbeta) \implies \bX^\top (\bY-\bX\bbeta)=0 \implies \hat{\bbeta} = (\bX^\top \bX)^{-1} \bX^\top \bY.
\]

In the general case, the optimal function is $f^*(\bx) = \EE[y \mid \bx]$, and the linear model approximates this conditional expectation as $\EE[y \mid \bx] = \bbeta^\top \bx$. To expand the function space and improve expressiveness, we sometimes apply a feature mapping to $\bx$. A simple example of a feature mapping is the polynomial mapping.
\paragraph{Splines}
For a partition $\zeta_0, \ldots, \zeta_K$ of the $x$-axis, define the indicator regressors
\[
\mathbf{z}_n^0 = \begin{pmatrix}
\mathrm{I}(\zeta_0 \leq x < \zeta_1) \\
\vdots \\
\mathrm{I}(\zeta_{K-1} \leq x < \zeta_K)
\end{pmatrix}.
\]
Regressing $y_n \sim \mathbf{z}_n^0$ produces a \emph{piecewise constant} fit, returning the average of training responses within each interval.
Indicator regressors give discontinuous fits with zero derivative. To obtain a piecewise linear fit, augment with
\[
\mathbf{z}_n^1 = \begin{pmatrix}
\mathrm{I}(\zeta_0 \leq x < \zeta_1)(x - \zeta_0) \\
\vdots \\
\mathrm{I}(\zeta_{K-1} \leq x < \zeta_K)(x - \zeta_{K-1})
\end{pmatrix}.
\]
Regressing $y_n \sim \mathbf{z}_n^0 + \mathbf{z}_n^1$ yields a separate first-order Taylor approximation within each segment.
Generalizing to degree $p$,
\[
\mathbf{z}_n^p = \begin{pmatrix}
\mathrm{I}(\zeta_0 \leq x < \zeta_1)(x - \zeta_0)^p \\
\vdots \\
\mathrm{I}(\zeta_{K-1} \leq x < \zeta_K)(x - \zeta_{K-1})^p
\end{pmatrix},
\]
gives a $p$-th order polynomial fit within each bucket.

\paragraph{Bias and Variance Trade-off}
Let’s decompose this target $\mathbb{E}\left[(\hat{f}(\mathbf{x}_{\mathrm{new}}) - y_{\mathrm{new}})^2\right]$.
\begin{align*}
\mathbb{E}\left[(\hat{f}(\mathbf{x}_{\mathrm{new}}) - y_{\mathrm{new}})^2\right]
&= \mathbb{E}\left[(\hat{f}(\mathbf{x}_{\mathrm{new}}) - \bar{f}(\mathbf{x}_{\mathrm{new}}) + \bar{f}(\mathbf{x}_{\mathrm{new}}) - f^{\star}(\mathbf{x}_{\mathrm{new}}) + f^{\star}(\mathbf{x}_{\mathrm{new}}) - y_{\mathrm{new}})^2\right] \\
&= \underbrace{\mathbb{E}\left[(\hat{f}(\mathbf{x}_{\mathrm{new}}) - \bar{f}(\mathbf{x}_{\mathrm{new}}))^2\right]}_{\text{``variance''}} + \underbrace{\mathbb{E}\left[(\bar{f}(\mathbf{x}_{\mathrm{new}}) - f^{\star}(\mathbf{x}_{\mathrm{new}}))^2\right]}_{\text{``bias''}} + \underbrace{\mathbb{E}\left[(f^{\star}(\mathbf{x}_{\mathrm{new}}) - y_{\mathrm{new}})^2\right]}_{\text{``irreducible error''}}.
\end{align*}
Define $M_{xx} = \EE [\bx^\top \bx]$ and $M_{xy} = \EE[\bx^\top y]$. Then $\bbeta = M_{xx}^{-1}M_{xy}$. By CLT,
\[
\hat{\bbeta} - \bbeta^*
= \left(\frac{1}{N} \sum_{n=1}^{N} \mathbf{x}_n \mathbf{x}_n^\top\right)^{-1} \frac{1}{N} \sum_{n=1}^{N} \mathbf{x}_n (y_n - \mathbf{x}_n^\top \mathbf{\beta}^*), \quad
\sqrt{N}(\hat{\bbeta} - \bbeta^*) \to \mathcal{N}(0, M_{xx}^{-1} U M_{xx}^{-1}),
\]
where $U := \operatorname{Cov}(\bx_n \epsilon_n)$. We have
\[
N \cdot\text{Variance} \approx \operatorname{tr}(M_{xx}^{-1/2} U M_{xx}^{-/2}) = \sigma^2\operatorname{tr}(I_P) = P\sigma^2 \implies \text{Variance} \approx \frac{P\sigma^2}{N}.
\]

\subsubsection{Ridge ($L_2$) and Lasso ($L_1$) Regression}
When $P \gg N$, $\bX^\top\bX$ is non-invertible, and the model is prone to overfitting---a common phenomenon in this regime. A simple remedy is to introduce a penalty term. We begin with the $L_2$ penalty.
\[
\mathcal{L}_{ridge}(\bbeta, \lambda) = \|\bY-\bX^\top\bbeta\|_2^2 + \lambda \|\bbeta\|_2^2 \implies \hat\bbeta_{ridge} = (\bX^\top \bX + \lambda \bI)^{-1} \bX^\top \bY.
\]
Assume $\bY = \bX^\top \bbeta^* + \bvarepsilon$ with $\mathbb{E}[\bvarepsilon] = \bzero$ and $\mathrm{Cov}(\bvarepsilon) = \sigma^2 \bI$. Let the singular value decomposition give $\bX^\top\bX = \bV \bSigma^2 \bV^\top$ with $\bSigma^2 = \mathrm{diag}(d_1, \ldots, d_P)$, so that $(\bX^\top\bX + \lambda \bI)^{-1} = \bV (\bSigma^2 + \lambda \bI)^{-1} \bV^\top$.

A direct computation gives
\[
\mathbb{E}[\hbbeta_{\text{ridge}}] - \bbeta^* = -\lambda \bV (\bSigma^2 + \lambda \bI)^{-1} \bV^\top \bbeta^*, \qquad \mathrm{Cov}(\hbbeta_{\text{ridge}}) = \sigma^2 \bV \, \mathrm{diag}\!\left(\frac{d_j}{(d_j+\lambda)^2}\right) \bV^\top,
\]
which yields
\[
\text{Bias: }\| \mathbb{E}[\hbbeta_{\text{ridge}}] - \bbeta^* \|_2^2 = \sum_{j=1}^{P} \frac{\lambda^2}{(d_j + \lambda)^2} (\bv_j^\top \bbeta^*)^2, \qquad \text{Variance: }\mathrm{tr}\,\mathrm{Cov}(\hbbeta_{\text{ridge}}) = \sigma^2 \sum_{j=1}^{P} \frac{d_j}{(d_j + \lambda)^2}.
\]
As $\lambda$ increases, the variance decreases while the bias increases.

Another choice is $L_1$ penalty, which we called LASSO,
\[
\mathcal{L}_{lasso}(\bbeta, \lambda) = \|\bY-\bX^\top\bbeta\|_2^2 + \lambda \|\bbeta\|_1.
\]
\begin{rem}
    LASSO favors \textbf{sparse} solutions, whereas Ridge spreads weight more evenly across coefficients. This makes LASSO a natural tool for variable selection: by tuning $\lambda$, one can identify the salient predictors as those with nonzero coefficients.
\end{rem}

\subsubsection{Kernel Methods}
Consider the Ridge Regression, by some Mathematics tricks
\[
\hat\bbeta_{ridge} = (\bX^\top \bX + \lambda \bI_P)^{-1} \bX^\top \bY = \bX(\bX \bX^\top + \lambda \bI_N)^{-1}  \bY.
\]
Note that we have replaced an $P\times P$ inverse with an $N\times N$ inverse, and may reduce computation (in some case). $\bX \bX^\top = (x_i^\top x_j)_{i,j}$, replace $x_i^\top x_j$ into $k(x_i,x_j)$, and we have kernel function.

\begin{defn}[Reproducing Kernel Hilbert Space]
Let $\cX$ be an arbitrary set and $\cH$ a Hilbert space of real-valued functions on $\cX$. We say $\cH$ is a \emph{reproducing kernel Hilbert space} (RKHS) if there is a kernel $k : \cX \times \cX \mapsto \mathbb{R}$ such that
\begin{itemize}
    \item $\forall x \in \cX,\ k(\cdot, x) \in \cH$.
    \item \emph{Reproducing property:} $\forall x \in \cX,\ f \in \cH,\ \langle f, k(\cdot, x) \rangle_\cH = f(x)$.
\end{itemize}
\end{defn}

For a kernel $k : \cX \times \cX \to \mathbb{R}$, we define an integral operator $\cT_k : L^2_\mu(\cX) \to L^2_\mu(\cX)$ as follows
\[
\cT_k f(x) = \mathbb{E}_{x' \sim \mu}[k(x, x') f(x')].
\]

\begin{thm}[Mercer's theorem]
Let $k$ be a continuous kernel on a \textbf{compact set} $\cX$. There exist an orthonormal basis $\{e_j\}_{j=1}^\infty$ of $L^2_\mu(\cX)$ such that $\forall x, x' \in \cX$,
\[
k(x, x') = \sum_{j=1}^{\infty} \lambda_j e_j(x) e_j(x').
\]
The convergence is uniform on $\cX \times \cX$ and absolute for each $(x, x') \in \cX \times \cX$.
\end{thm}
\begin{rem}
    From this perspective, an RKHS can be viewed as a subspace of $L_2$. The faster the eigenvalues $\lambda_j$ decay, the smaller the RKHS---and correspondingly, the smoother the functions it contains.
\end{rem}

This theorem ensures the existence of an eigendecomposition of a kernel $k$, i.e., the corresponding integral operator $\cT_k$. Note that $(\lambda_j)_{j \geq 1}$ and $(e_j)_{j \geq 1}$ are the eigenvalues and eigenfunctions of the integral operator $\cT_k$ in the sense that
\begin{itemize}
    \item $\cT_k e_j = \lambda_j e_j$, i.e., $\mathbb{E}_{x' \sim \mu}[k(x, x') e_j(x')] = \lambda_j e_j(x)$.
    \item $\langle e_i, e_j \rangle_{L^2_\mu(\cX)} = \mathbb{E}_{x \sim \mu}[e_j(x) e_i(x)] = \delta_{i,j}$.
\end{itemize}

\paragraph{Feature map.} Mercer's theorem gives a feature map for the kernel $k$. Let
\[
\Phi : \cX \to \ell^2, \qquad \Phi(x) = \left(\sqrt{\lambda_1} e_1(x), \sqrt{\lambda_2} e_2(x), \ldots, \sqrt{\lambda_j} e_j(x), \ldots\right)^\top.
\]
Then,
\[
k(x, x') = \sum_{j=1}^{\infty} \sqrt{\lambda_j} e_j(x) \sqrt{\lambda_j} e_j(x') = \langle \Phi(x), \Phi(x') \rangle_{\ell^2}.
\]

\begin{thm}[Spectral representation of RKHS]
Let $k$ be a continuous kernel on a compact set $\cX$, and $\{e_j\}$ be the orthonormal basis given in Mercer's theorem. Define
\[
\cH = \left\{ f = \sum_j a_j e_j : \sum_j \frac{a_j^2}{\lambda_j} < \infty \right\},
\]
with the inner product
\[
\left\langle \sum_j a_j e_j, \sum_j b_j e_j \right\rangle_{\cH} = \sum_j \frac{a_j b_j}{\lambda_j}.
\]
Then, $\cH$ is the RKHS $\cH_k$.
\end{thm}

\subsection{Classification}
\subsubsection{Fundamentals}
Let us now turn to classification problems. Like regression, we assume we get IID observations $z_n = (\mathbf{x}_n, y_n)$, but now with the difference that $y$ takes one of a set of unordered distinct values, which I will call $\mathcal{Y}$. The simplest case is where $y$ takes one of two values, which I will sometimes call ``binary classification''. As before, we wish to use $\mathbf{x}$ to guess what $y$ is. As we will see shortly, there are more choices to what $f$ should even be for classification than there are for regression.

Ultimately, we need a mapping $\mathbf{x} \mapsto \mathcal{Y}$, so we might take $\hat{y}(\mathbf{x}) \in \mathcal{Y}$. Necessarily, the loss function must take in two values in $\mathcal{Y}$---the guess and the truth---and return a real number. Formally, $\mathscr{L}: \mathcal{Y} \times \mathcal{Y} \mapsto \mathbb{R}$, which can be fully represented as a $|\mathcal{Y}| \times |\mathcal{Y}|$ matrix.
The simplest case of this is called ``zero--one'' loss:
\[
\mathscr{L}_{\text{ZO}}(\hat{y}, y) = \mathrm{I}(\hat{y} \neq y) = \sum_{c \in \mathcal{Y}} \mathrm{I}(\hat{y} = c)\, \mathrm{I}(y \neq c).
\]
Note that the maximizer of the zero--one loss has a closed form:
\begin{align*}
\mathbb{E}_{\mathbb{P}(\mathbf{x},y)}\left[\mathscr{L}_{\text{ZO}}(\hat{y}, y)\right]
&= \sum_{c \in \mathcal{Y}} \mathrm{I}(\hat{y} = c)\, \mathbb{E}_{\mathbb{P}(\mathbf{x},y)}\left[\mathrm{I}(y \neq c)\right] \\
&= \sum_{c \in \mathcal{Y}} \mathrm{I}(\hat{y} = c)\bigl(1 - \mathbb{P}(y = c, \mathbf{x})\bigr) \\
&= 1 - \sum_{c \in \mathcal{Y}} \mathrm{I}(\hat{y} = c)\bigl(1 - \mathbb{P}(y = c \mid \mathbf{x})\bigr)\mathbb{P}(\mathbf{x}).
\end{align*}
Since $\mathbb{P}(\mathbf{x})$ does not depend on $c$, the best choice for $\hat{y}$ is
\begin{equation*}
\hat{y}^*(\mathbf{x}) = \operatorname*{argmax}_{c \in \mathcal{Y}} \mathbb{P}(y = c \mid \mathbf{x}).
\end{equation*}

The natural generalization of zero--one loss and functions that return categories is a function that returns a probability. For binary regression with $y \in \{0, 1\}$, we can take $\pi(\mathbf{x})$ to approximate $\mathbb{P}(y = 1 \mid \mathbf{x})$, and so take $\pi: \mathbf{x} \mapsto [0, 1]$.

\paragraph{Cross Entropy Loss}
If $\pi(\mathbf{x}) \in (0, 1)$ then we can in fact use other losses. One common choice is the negative log likelihood:
\begin{align*}
\mathscr{L}_{\text{CE}}(\pi, y)
&= -\log \mathbb{P}(y \mid \pi) \\
&= -\log \pi^{y}(1 - \pi)^{1-y} \\
&= -y \log \pi - (1-y) \log(1 - \pi) \\
&= -y \log \frac{\pi}{1 - \pi} - \log(1 - \pi).
\end{align*}
This is also known as the ``cross-entropy loss,'' since the maximum likelihood estimator is also the minimizer of the Kullback--Liebler divergence.

\paragraph{Logistic Regression}
Suppose we have $f \in \mathbb{R}$. Then
\begin{equation*}
\pi(f) = \frac{\exp(f)}{1 + \exp(f)} =: \operatorname{Expit}(f).
\end{equation*}
You can readily see that $\operatorname{Expit}(f) \in (0, 1)$.
The expit function is invertible with inverse sometimes called the ``logit'':
\begin{equation*}
\operatorname{Logit}(\pi) := \log \frac{\pi}{1 - \pi}.
\end{equation*}
Note that if you plug this formula into the cross-entropy loss,
\begin{align*}
\mathscr{L}_{\text{CE}}(\operatorname{Expit}(f), y)
&= -y \operatorname{Logit}(\operatorname{Expit}(f)) + \log(1 - \operatorname{Expit}(f)) \\
&= -y f + \log\!\left(1 - \frac{\exp(f)}{1 + \exp(f)}\right) \\
&= -y f - \log(1 + \exp(f)),
\end{align*}
And if we further take $f(\mathbf{x}) = \mathbf{\beta}^{\top} \mathbf{x}$, we get
\begin{equation*}
\mathscr{L}_{\text{CE}}(\operatorname{Expit}(\mathbf{\beta}^{\top}\mathbf{x}), y) = -y \mathbf{\beta}^{\top} \mathbf{x} - \log(1 + \exp(\mathbf{\beta}^{\top}\mathbf{x})),
\end{equation*}
which is \textbf{logistic regression}.

\paragraph{Generative modeling}
We have noted that the optimal classifier takes the form of the maximum of $\mathbb{P}(y = c \mid \mathbf{x})\mathbb{P}(\mathbf{x})$. In our reasoning above we ignored $\mathbb{P}(\mathbf{x})$ since it does not depend on $c$, and modeled $\mathbb{P}(y = c \mid \mathbf{x})$, e.g.\ using the expit function and linear models.
However, we could condition in the other direction to write
\begin{equation*}
\hat{y} = \operatorname*{argmax}_{c} \mathbb{P}(y = c \mid \mathbf{x})\mathbb{P}(\mathbf{x}) = \operatorname*{argmax}_{c} \mathbb{P}(\mathbf{x} \mid y = c)\mathbb{P}(y = c).
\end{equation*}
When we have many more data than categories, $\mathbb{P}(y = c)$ is easy to estimate:
\begin{equation*}
\mathbb{P}(y = c) \approx \frac{1}{N} \sum_{n=1}^{N} \mathrm{I}(y_n = c).
\end{equation*}
We can then attempt to model the conditional density $\mathbb{P}(\mathbf{x} \mid y = c)$ by forming density estimates the sets of points $\mathcal{X}_c := \{\mathbf{x}_n : y_n = c\}$. Density estimation is difficult in high dimensions---arguably more difficult than estimating good decision boundaries---but generative modeling can be particularly effective in low dimensions, or when something special is known about the structure of $\mathbb{P}(\mathbf{x} \mid y = c)$.

Note that the estimation $\mathbb{P}(\mathbf{x} \mid y = c)$ does not admit a ready formulation as a direct minimization of classification error. Estimation of densities is typically considered an \textbf{``unsupervised learning''} problem for this reason, even though here we would use the unsupervised learning estimate in service of a supervised learning problem.

\subsubsection{Support Vector Machines}
Suppose we have binary classification data $(\mathbf{x}_1, y_1), \ldots, (\mathbf{x}_N, y_N)$, where $y_n \in \{-1, 1\}$, and we want to find a linear decision boundary:
\begin{equation*}
\hat{y}_n = \operatorname{sign}(\mathbf{x}_n^{T} \hat{\mathbf{\beta}}).
\end{equation*}
Such a vector $\hat{\mathbf{\beta}}$ would be normal to a hyperplane that separates our predictions.
Support Vector Machines add three layers on top of this:
\begin{itemize}
    \item \textbf{Regularization}: find the separating hyperplane with maximum margin.
    \item \textbf{Soft margin}: allow for margin mistakes (e.g.\ not linearly separable).
    \item \textbf{Kernel}: expressive (possibly infinite) feature mapping.
\end{itemize}

For finite data that are linearly separable, there always are infinitely many separating hyperplanes. Which one does perceptron converge to? If it does, con implicit, so let's make it implicit and ask for a particular one. As a form of regularization, we'll ask for the one with maximum margin:
\begin{equation*}
\hat{\mathbf{\beta}}_{\text{hard}} = \operatorname*{argmax}_{\|\mathbf{\beta}\|_2 = 1,\, \gamma} \gamma \quad \text{subject to} \quad y_n \mathbf{x}_n^{T} \mathbf{\beta} \geq \gamma \quad \forall n = 1, \ldots, N.
\end{equation*}
\begin{prop}
\begin{equation*}
\hat{\mathbf{\beta}}_{\text{hard}} = \operatorname*{argmin}_{\mathbf{\beta}} \|\mathbf{\beta}\|_2 \quad \text{subject to} \quad y_n \mathbf{x}_n^{T} \mathbf{\beta} \geq 1 \quad \forall n = 1, \ldots, N.
\end{equation*}
\end{prop}

\paragraph{Soft Margin SVM}
The hard margin SVM is restricted to linearly separable data. We now introduce a soft margin (linear) SVM, which trades separability with $\|\mathbf{\beta}\|_2$:
\begin{equation*}
\hat{\mathbf{\beta}}_{\text{soft}}(\lambda) = \operatorname*{argmin}_{\mathbf{\beta}} \sum_{n=1}^{N} \max(1 - y_n \mathbf{x}_n^{T} \mathbf{\beta},\, 0) + \lambda \|\mathbf{\beta}\|_2^2.
\end{equation*}
This way, we may allow classification (or margin) mistakes for the purpose of reducing $\|\mathbf{\beta}\|_2^2$. This brings us to the familiar form of minimizing loss plus penalty.

\paragraph{Connection to hard margin SVM}
To see how soft margin SVM relates to hard margin, add slack variable $\xi_n \geq \max(1 - y_n \mathbf{x}_n^{T} \mathbf{\beta},\, 0)$ and observe that
\begin{equation*}
\hat{\mathbf{\beta}}_{\text{soft}}(\lambda) = \operatorname*{argmin}_{\mathbf{\beta}} \|\mathbf{\beta}\|_2^2 + \frac{1}{\lambda} \sum_{n=1}^{N} \xi_n \quad \text{subject to} \quad y_n \mathbf{x}_n^{T} \mathbf{\beta} \geq 1 - \xi_n,\; \xi_n \geq 0 \quad \forall n = 1, \ldots, N.
\end{equation*}

We also divided by $\lambda$. From this point we may intuitively believe that, for linearly separable data, $\hat{\mathbf{\beta}}_{\text{hard}}$ is obtained as the limit of $\hat{\mathbf{\beta}}_{\text{soft}}(\lambda)$ as $\lambda \to 0^{+}$, since the slack variables $\xi_1, \ldots, \xi_N$ are pushed to zero.

\paragraph{Interpretation as penalty for margin mistakes}
The slack variable $\xi_n$ is nonzero if we make a margin mistake on $(\mathbf{x}_n, y_n)$. It is greater than one if we make a classification mistake. The sum $\sum_{n=1}^{N} \xi_n$ quantifies the total over all margin mistakes, which we can control by adjusting the penalty $\lambda$.

\paragraph{Kernels}
Using convex optimization theory, one may show that the soft margin SVM solution will satisfy
\begin{equation*}
\hat{\mathbf{\beta}}_{\text{soft}} = \sum_{n=1}^{N} \alpha_n y_n \mathbf{x}_n \quad ; \quad \text{where} \quad \alpha_n \neq 0 \text{ if and only if } y_n \mathbf{x}_n^{T} \hat{\mathbf{\beta}}_{\text{soft}} \leq 1.
\end{equation*}
If we used an expressive feature transformation $\varphi(\mathbf{x}_n) \in \mathbb{R}^{Q}$, the soft margin SVM $\hat{\mathbf{\beta}}_{\text{kernel}} \in \mathbb{R}^{Q}$ would satisfy
\begin{equation*}
\hat{\mathbf{\beta}}_{\text{kernel}} = \sum_{n=1}^{N} \alpha_n y_n \varphi(\mathbf{x}_n).
\end{equation*}
The prediction on a new observation would be
\begin{equation*}
y = \operatorname{sign}\!\left(\varphi(\mathbf{x})^{T} \hat{\mathbf{\beta}}_{\text{kernel}}\right) = \sum_{n=1}^{N} \alpha_n y_n \varphi(\mathbf{x})^{T} \varphi(\mathbf{x}_n)=: \sum_{n=1}^{N} \alpha_n y_n k(\mathbf{x},\mathbf{x}_n).
\end{equation*}

Classification and Regression Trees (CART) is a tree-based method that recursively splits the data into two groups based on feature values, producing a model that can predict either a category or a numerical value.

In order to choose a more optimal tree, we ``trim'' the tree back by regularizing the size of the tree. Given a starting tree $T$ and a cost complexity parameter $\alpha$, we find the subtree that minimizes
\begin{equation}
    \text{Cost complexity}\,(T') = \sum_{t \in T'} \sum_{n \in t} (y_n - \hat{y}_t)^2 + \alpha |T'|,
\end{equation}
where $t \in T'$ means $t$ is a leaf node of $T'$, $n \in t$ means $\mathbf{x}_n$ is assigned to leaf node $t$, and $|T'|$ counts the number of leaf nodes.

\subsubsection{Bootstrapping}
Let $Y_1, \ldots, Y_N$ be i.i.d.\ observations from an unknown
distribution $F$, and let $\hat{\mu} = s(\boldsymbol{Y})$ be an
estimator of a parameter $\mu$. The \emph{bootstrap} approximates
the sampling distribution of $\hat{\mu}$ by replacing $F$ with the
empirical distribution
\[
  \hat{F}(y) \;=\; \frac{1}{N}\sum_{i=1}^{N} \mathbb{I}(Y_i \le y),
\]
and resampling from the data itself. For $b = 1, \ldots, R$, draw
$\boldsymbol{Y}^{*b} = (Y_1^{*b}, \ldots, Y_N^{*b})$ \textbf{with
replacement} from $\{Y_1, \ldots, Y_N\}$ and compute the bootstrap
replicate $\hat{\mu}^{*b} = s(\boldsymbol{Y}^{*b})$. The empirical
distribution of $\{\hat{\mu}^{*1}, \ldots, \hat{\mu}^{*R}\}$ then
serves as a proxy for the sampling distribution of $\hat{\mu}$.
\begin{rem}
    Bootstrapping's power is
    computational rather than informational: it does not see more than the data, but it extracts what closed-form derivations would discard.
\end{rem}



\subsubsection{Bagging}
Suppose we're using squared error loss, and we have a learner that is
approximately \textbf{unbiased but high variance}. That is, for a particular
fixed $x$, we have $\hat{f}(x; \mathcal{D})$, where $\hat{f}(\cdot; \mathcal{D})$
depends on the training data $\mathcal{D}$, which satisfies
\[
\mathbb{E}_{\mathcal{D}}\left[\hat{f}(x; \mathcal{D})\right] \approx f^*(x)
\quad \text{and} \quad
\mathrm{Var}_{\mathcal{D}}\left(\hat{f}(x; \mathcal{D})\right) \text{ is large.}
\]
Here, $\mathbb{E}\left[y \mid x\right] = f^*(x)$ is the best possible
prediction we could make.

One might think of deep regression trees as being a possible example.
Intuitively, one might expect such a predictor to be over-fitting the
particular dataset at hand.

Recall that we showed earlier that the expected squared error decomposes into
\[
\mathbb{E}_{\mathcal{D}}\left[(\hat{f}(x; \mathcal{D}) - f^*(x))^2\right]
= \underbrace{\mathbb{E}_{\mathcal{D}}\left[\left(\hat{f}(x; \mathcal{D})
- \mathbb{E}_{\mathcal{D}}\left[\hat{f}(x; \mathcal{D})\right]\right)^2\right]}_{\text{Variance}}
+ \underbrace{\left(\mathbb{E}_{\mathcal{D}}\left[\hat{f}(x; \mathcal{D})\right]
- f^*(x)\right)^2}_{\text{Bias}}.
\]

The variance only increases the expected squared error, so if we could
get a lower-variance estimator without changing the bias, we'd improve
our loss. Ideally, we might imagine getting $B$ different, new datasets
$\mathcal{D}_1, \ldots, \mathcal{D}_B$, and then using
\[
\hat{f}_{\text{Ideal}}(x) = \frac{1}{B} \sum_{b=1}^{B} \hat{f}(x; \mathcal{D}_b)
\approx \mathbb{E}_{\mathcal{D}}\left[\hat{f}(x; \mathcal{D})\right].
\]

Of course, if we could actually do this, we should just combine the
datasets into one giant dataset. But this idea motivates the feasible
``bagging'' estimator:
\[
\hat{f}_{\text{Bagging}}(x) = \frac{1}{B} \sum_{b=1}^{B} \hat{f}(x; \mathcal{D}_b^*),
\]
where $\mathcal{D}_b^*$ is a \emph{bootstrap} sample from the original
dataset. The bootstrap distribution is a random distribution
\emph{conditional on the original dataset} $\mathcal{D}$, with probability
distribution
\[
\mathbb{P}\left((x_n^*, y_n^*) = (x_n, y_n)\right) = \frac{1}{N}
\quad \text{for} \quad n = 1, \ldots, N.
\]

The problem is, of course, that bootstrap draws are not draws from
$\mathcal{D}$. Why does bagging work? In my opinion, the theory is not
very clear, but it appears in practice that bagging tends to improve
highly variable and expressive estimators, but can make less variable
estimators worse.

\subsubsection{Boosting}
\begin{algorithm}[H]
\caption{Forward stagewise additive modeling}
\label{alg:forward-stagewise}
\begin{algorithmic}
  \Statex \textbf{Input:} training data $\{(\boldsymbol{x}_n,y_n)\}_{n=1}^{N}$,
    loss $\mathcal{L}$, and stages $M$; \quad
    \textbf{Output:} predictor $\hat{f}_M$
  \State Initialize $\hat{f}_0(\cdot) \gets 0$
  \For{$m = 1, \ldots, M$}
    \State Choose the next coefficient and weak learner:
    \Statex \hspace{\algorithmicindent}$\displaystyle
      (\hat{\theta}_m,\hat{\phi}_m)
      \gets \operatorname*{argmin}_{\theta,\phi}
      \frac{1}{N}\sum_{n=1}^{N}
      \mathcal{L}\!\left(
        \hat{f}_{m-1}(\boldsymbol{x}_n)
        + \theta\phi(\boldsymbol{x}_n),y_n
      \right)$
    \State Update $\hat{f}_m(\cdot) \gets \hat{f}_{m-1}(\cdot)
      + \hat{\theta}_m\hat{\phi}_m(\cdot)$
  \EndFor
  \State \Return $\displaystyle \hat{f}_M(\cdot)
    = \sum_{m=1}^{M}\hat{\theta}_m\hat{\phi}_m(\cdot)$
\end{algorithmic}
\end{algorithm}
For boosting, we first find the $\hat{f}_1(\cdot)$ that best
predicts $y_n$, then the one that makes the biggest improvement when
added to $\hat{f}_1(\cdot)$, and so on. Note that at each step all we
need to be able to do is make a \emph{small improvement}, since over
$M$ steps these small improvements accumulate. For example, we might
take $\hat{\phi}_m(\cdot)$ to simply be a ``stump'': a regression
tree with a single split. In this sense, boosting can improve on
\textbf{high-biased estimators} by adding up a large number of them in an
\textbf{increasingly expressive} way.

\subsection{Cross-Validation}
\subsubsection{Cross-Validation}
We spend some time developing theory to control the generalization
error, $\hat{\mathcal{L}}(\hat{f}) - \mathcal{L}(\hat{f})$. In
practice, however, this theory is not useful because we cannot
actually compute the complexity. More importantly, the worst-case
bounds we computed appear in practice to be \emph{too loose} and may
suggest bad advice (see, e.g., Belkin et al.\ (2019)). In practice,
we most often \emph{estimate} the risk $\mathcal{L}(\hat{f})$ using
held-out data.

Recall that the estimator
$\hat{\mathcal{L}}(\hat{f}) = \frac{1}{N}\sum_{n=1}^{N}
\mathcal{L}(\hat{f}(\boldsymbol{x}_n), y_n)$ is not considered a
reliable estimator of $\mathcal{L}(\hat{f})$ because $\hat{f}$ is
not independent of $(\boldsymbol{x}_n, y_n)$. But suppose we have
an actual new dataset,
$\mathcal{D}_{\text{new}} = ((\boldsymbol{x}_1, y_1), \ldots,
(\boldsymbol{x}_M, y_M))$. Then we could just estimate:
\[
  \hat{\mathcal{L}}_{\text{new}}(\hat{f})
  \;\approx\; \frac{1}{M}\sum_{m=1}^{M}
  \mathcal{L}(\hat{f}(\boldsymbol{x}_m), y_m).
\]
This \emph{is} a consistent estimate of $\mathcal{L}(\hat{f})$ since
we did not use $\mathcal{D}_{\text{new}}$ to train $\hat{f}$, and so
$\hat{f}$ is independent of $\boldsymbol{x}_m, y_m$.

One might ask, if you had $\mathcal{D}_{\text{new}}$, why didn't you
just use it to train $\hat{f}$? Conversely, you might imagine taking
the data you do have, and splitting it (randomly) into a ``training
set'' $\mathcal{D}_{\text{train}}$ and a ``test set''
$\mathcal{D}_{\text{test}}$, using only $\mathcal{D}_{\text{train}}$
to compute $\hat{f}$, and $\mathcal{D}_{\text{test}}$ to estimate
$\hat{\mathcal{L}}_{\text{test}}(\hat{f})$ using the above formula.
There are costs and benefits to doing this:
\begin{itemize}
  \item You have less data to train $\hat{f}$.
  \item You have a good estimate of $\mathcal{L}(\hat{f})$.
\end{itemize}
Putting more data in $\mathcal{D}_{\text{train}}$ ameliorates the
first cost, at the risk of making your estimate of
$\mathcal{L}(\hat{f})$ worse.

A clever way to use nearly all the data to compute $\hat{f}$ and
still get a reasonable test set error is to \emph{repeat} the above
procedure many times, each time with a different test set.

As an extreme, let $\hat{f}_{-n}$ denote an estimate of $\hat{f}$
with the $n$-th datapoint removed. Since you have removed only one
datapoint, we might hope that $\hat{f}_{-n} \approx \hat{f}$, so we
have paid little estimation cost. Of course, the estimate
\[
  \hat{\mathcal{L}}_{\text{test}}(\hat{f}_{-n})
  \;=\; \mathcal{L}(\hat{f}_{-n}(\boldsymbol{x}_n), y_n)
\]
uses a single datapoint, and so is very variable, if nearly
unbiased. However, we can do this for \emph{each} datapoint and
average the results to reduce the variance of the test error
estimate. This is called the ``leave-one-out CV estimator,'' or
LOO-CV:
\[
  \hat{\mathcal{L}}_{\text{LOO}}
  \;:=\; \frac{1}{N}\sum_{n=1}^{N}
  \mathcal{L}(\hat{f}_{-n}(\boldsymbol{x}_n), y_n).
\]
Of course, you can do the same thing leaving two points out, or
three, or so on, giving ``leave-$k$-out CV'' estimators. In the
extreme where you leave a fraction $N/K$ points out, you get
``$K$-fold'' CV estimators.

How many should you leave out? There seems to be a striking lack of
useful theory. The rules of thumb are:
\begin{itemize}
  \item By leaving out more datapoints you ``bias'' your estimate
        if your estimate of $\hat{f}$ depends strongly on how many
        datapoints you have.
  \item By leaving out more datapoints you reduce the ``variance''
        of your estimate of $\mathcal{L}(\hat{f})$ by making the
        test set larger.
\end{itemize}
So there appears to be a sort of meta-bias-variance tradeoff in the
estimation of $\mathcal{L}(\hat{f})$. Common practice is five- or
ten-fold cross-validation.

\subsubsection{Influence Function}
The influence function estimates how the model parameters (or predictions)
change when a training sample is slightly perturbed, without retraining.

Let the parameters $\hat\theta$ minimize the empirical risk
$\hat\theta = \arg\min_{\theta} \frac{1}{n}\sum_{i=1}^{n} \mathcal{L}(z_i,\theta)$.
Now upweight the $i$-th sample by a small $\epsilon$, giving the perturbed
optimizer
\[
  \hat\theta_{\epsilon,z_i}
  = \arg\min_{\theta}\ \frac{1}{n}\sum_{j=1}^{n} \mathcal{L}(z_j,\theta)+\epsilon\,\mathcal{L}(z_i,\theta).
\]

Differentiating with respect to $\epsilon$ at $\epsilon=0$ yields the influence
of this sample on the parameters,
\[
  \mathcal{I}_{\text{params}}(z_i)
  = \left.\frac{d\hat\theta_{\epsilon,z_i}}{d\epsilon}\right|_{\epsilon=0}
  = -\,H_{\hat\theta}^{-1}\,\nabla_\theta \mathcal{L}(z_i,\hat\theta),
\]
where $H_{\hat\theta}=\frac{1}{n}\sum_{i=1}^{n}\nabla_\theta^2 \mathcal{L}(z_i,\hat\theta)$
is the Hessian. Since deleting a sample corresponds to $\epsilon=-\tfrac{1}{n}$,
the parameter change from removal is approximately
$-\tfrac{1}{n}\,\mathcal{I}_{\text{params}}(z_i)$.

By the chain rule, the influence of a training sample $z$ on the loss at a test
point $z_{\text{test}}$ is
\[
  \mathcal{I}(z,z_{\text{test}})
  = -\,\nabla_\theta \mathcal{L}(z_{\text{test}},\hat\theta)^{\top}\,
       H_{\hat\theta}^{-1}\,
       \nabla_\theta \mathcal{L}(z,\hat\theta).
\]
Intuitively, the more aligned the two gradients are after weighting by
$H_{\hat\theta}^{-1}$, the more the training sample $z$ helps that prediction.

\subsection{Time Series}
This subsection follows the conceptual arc of UC Berkeley STAT 153/248
\cite{hamilton2026stat153} and parts of \cite{shumway2025time}. We will not repeat
linear regression or general model selection. Instead, we focus on what is
special about ordered data: dependence, forecasting from the past, and models
whose structure respects time.

\subsubsection{Dependence, stationarity, and forecasting}
A \textbf{time series} is one observed path $X_1,\ldots,X_n$ of a stochastic
process $\{X_t\}_{t\in\mathbb{Z}}$. Unlike an iid sample, the ordering is part of
the data. Usually $X_t$ is informative about $X_{t+1}$, and often we observe only
one realization rather than many independent copies of the whole process.

Let
\[
    \mathcal{F}_t=\sigma(X_s:s\leq t)
\]
denote the information available at time $t$. Under squared error loss, the best
$h$-step-ahead forecast is the conditional mean
\[
    \widehat{X}_{t+h\mid t}
    =\mathbb{E}[X_{t+h}\mid\mathcal{F}_t].
\]
This formula is deliberately abstract. Every forecasting model---ARMA, a state
space model, a convolutional network, or a recurrent network---is a different
way to summarize $\mathcal{F}_t$ well enough to approximate this conditional
expectation.

The simplest benchmark is \textbf{white noise}. A sequence $\{\varepsilon_t\}$
is white noise with variance $\sigma^2$, written
$\varepsilon_t\sim\mathrm{WN}(0,\sigma^2)$, if
\[
    \mathbb{E}[\varepsilon_t]=0,\qquad
    \operatorname{Var}(\varepsilon_t)=\sigma^2,\qquad
    \operatorname{Cov}(\varepsilon_t,\varepsilon_s)=0\quad(t\neq s).
\]
White noise need not be independent. Gaussian white noise is special: because a
Gaussian vector is independent exactly when it is uncorrelated, it is an iid
Gaussian sequence.

To learn dependence from a single path, we need some stability across time.

\begin{defn}[Weak stationarity]
A finite-variance process $\{X_t\}$ is \textbf{weakly stationary} if, for some
constant $\mu$ and function $\gamma$,
\[
    \mathbb{E}[X_t]=\mu,
    \qquad
    \operatorname{Cov}(X_{t+h},X_t)=\gamma(h)
\]
for every $t$ and $h$. Its autocorrelation function (ACF) is
$\rho(h)=\gamma(h)/\gamma(0)$.
\end{defn}

Stationarity says that the covariance between two observations depends on their
separation, not their calendar location. This lets different time windows act as
comparable replicates. For a stationary series, natural estimates are
\[
    \widehat{\gamma}(h)
    =\frac{1}{n}\sum_{t=1}^{n-h}(X_{t+h}-\overline{X})(X_t-\overline{X}),
    \qquad
    \widehat{\rho}(h)=\frac{\widehat{\gamma}(h)}{\widehat{\gamma}(0)}.
\]
Strict stationarity requires the entire joint distribution to be invariant under
time shifts; weak stationarity only asks for invariance of the first two moments.
For linear prediction, the weaker notion is often enough. Stationarity alone does
not guarantee that time averages converge to population averages; that additional
role is played by ergodicity or suitable mixing conditions.

\begin{exam}[A random walk is not stationary]
Let $X_t=X_{t-1}+\varepsilon_t$ with $X_0=0$ and iid innovations of variance
$\sigma^2$. Then
\[
    X_t=\sum_{j=1}^t\varepsilon_j,
    \qquad
    \operatorname{Var}(X_t)=t\sigma^2,
    \qquad
    \operatorname{Cov}(X_s,X_t)=\sigma^2\min(s,t).
\]
The variance grows with time and the covariance depends on $s$ and $t$, not only
on $|t-s|$. However, the differences
$\Delta X_t=X_t-X_{t-1}=\varepsilon_t$ are stationary. This is the basic idea
behind integrated models: model stable increments rather than an unstable level.
\end{exam}

\begin{rem}[Time-respecting evaluation]
Randomly splitting a dependent series leaks information between training and
test sets and may even train on the future to predict the past. Forecasts should
be evaluated chronologically, for example by repeatedly training on
$X_{1:t}$ and testing on $X_{t+1:t+h}$. The forecasting origin moves forward;
time does not get shuffled.
\end{rem}

\subsubsection{The time and frequency views}
The ACF describes dependence by lag. The spectral density describes the same
second-order structure by frequency. If $\sum_h|\gamma(h)|<\infty$, define
\[
    f(\omega)
    =\frac{1}{2\pi}\sum_{h=-\infty}^{\infty}\gamma(h)e^{-\ii\omega h},
    \qquad -\pi\leq\omega\leq\pi.
\]
Fourier inversion gives
\[
    \gamma(h)=\int_{-\pi}^{\pi}f(\omega)e^{\ii\omega h}\,\dd\omega,
    \qquad
    \operatorname{Var}(X_t)=\gamma(0)=\int_{-\pi}^{\pi}f(\omega)\,\dd\omega.
\]
Thus $f(\omega)$ decomposes variance by frequency: a peak near zero means slow,
persistent variation, while a peak away from zero suggests oscillation. The time
and frequency domains are not rival explanations; they are Fourier transforms of
the same covariance information.

For observed data, the periodogram
\[
    I_n(\omega)
    =\frac{1}{2\pi n}
      \left|\sum_{t=1}^n(X_t-\overline{X})e^{-\ii\omega t}\right|^2
\]
reveals prominent frequencies. A raw periodogram remains noisy even when $n$ is
large, so estimating a smooth spectrum usually requires averaging or smoothing
nearby frequencies.

Filtering also becomes transparent in this view. If
$Y_t=\sum_j a_jX_{t-j}$ and $A(z)=\sum_j a_jz^j$, then
\[
    f_Y(\omega)=|A(e^{-\ii\omega})|^2f_X(\omega).
\]
A moving average suppresses frequencies at which its transfer function $A$ is
small. This observation will later connect classical linear filters to
one-dimensional convolutional networks.

\subsubsection{ARMA models}
We now turn to the central model class. Define the backshift operator
$BX_t=X_{t-1}$. For polynomials
\[
    \phi(z)=1-\phi_1z-\cdots-\phi_pz^p,
    \qquad
    \theta(z)=1+\theta_1z+\cdots+\theta_qz^q,
\]
an $\operatorname{ARMA}(p,q)$ process satisfies
\[
    \phi(B)(X_t-\mu)=\theta(B)\varepsilon_t,
    \qquad \varepsilon_t\sim\mathrm{WN}(0,\sigma^2).
\]
Equivalently,
\[
    X_t-\mu
    =\sum_{j=1}^p\phi_j(X_{t-j}-\mu)
     +\varepsilon_t+\sum_{j=1}^q\theta_j\varepsilon_{t-j}.
\]
The AR part propagates past states; the MA part propagates past shocks. Notice
that a time-series MA model averages latent innovations, not observed data. It
should not be confused with the moving-average smoother used to remove noise.

\paragraph{The AR(1) model}
\hspace{0.55em}Consider
\[
    X_t-\mu=\phi(X_{t-1}-\mu)+\varepsilon_t.
\]
Iterating backward gives
\[
    X_t-\mu
    =\varepsilon_t+\phi\varepsilon_{t-1}+\phi^2\varepsilon_{t-2}+\cdots.
\]
This causal stationary representation exists when $|\phi|<1$. In that case,
\[
    \operatorname{Var}(X_t)=\frac{\sigma^2}{1-\phi^2},
    \qquad
    \rho(h)=\phi^{|h|}.
\]
Positive $\phi$ creates persistent motion, negative $\phi$ creates alternating
motion, and $|\phi|$ determines how quickly memory decays. At $\phi=1$, shocks
never decay and the model becomes the nonstationary random walk.

The $h$-step forecast and its error variance are especially revealing:
\[
\begin{aligned}
    \widehat{X}_{t+h\mid t}
        &=\mu+\phi^h(X_t-\mu),\\
    \operatorname{Var}(X_{t+h}-\widehat{X}_{t+h\mid t}\mid\mathcal{F}_t)
        &=\sigma^2\sum_{j=0}^{h-1}\phi^{2j}
          =\sigma^2\frac{1-\phi^{2h}}{1-\phi^2}.
\end{aligned}
\]
The point forecast forgets the present at rate $|\phi|^h$, while forecast
uncertainty grows toward the unconditional variance. These are two sides of the
same loss of memory.

\paragraph{The MA(1) model}
\hspace{0.55em}Now consider
\[
    X_t=\varepsilon_t+\theta\varepsilon_{t-1}.
\]
It is stationary for every finite $\theta$, with
\[
    \gamma(0)=\sigma^2(1+\theta^2),\qquad
    \rho(1)=\frac{\theta}{1+\theta^2},\qquad
    \rho(h)=0\quad(|h|>1).
\]
The shock $\varepsilon_t$ affects only $X_t$ and $X_{t+1}$, so the ACF cuts off
after one lag. By contrast, an AR(1) shock has a geometrically decaying effect
forever.

There is an identifiability issue: $\theta$ and $1/\theta$ generate the same ACF,
and a rescaling of $\sigma^2$ can make their autocovariances identical. We choose
the \textbf{invertible} representation $|\theta|<1$, for which the innovations can
be recovered from the observed past:
\[
    \varepsilon_t=(1+\theta B)^{-1}X_t
    =\sum_{j=0}^{\infty}(-\theta)^jX_{t-j}.
\]
Invertibility is therefore both a stability condition and a convention that
selects one observable representation among equivalent ones.

\paragraph{General ARMA models}
\hspace{0.55em}For $\phi$ and $\theta$ with no common roots, the usual forecasting model is
causal when every root of $\phi(z)=0$ lies outside the unit circle, and invertible
when every root of $\theta(z)=0$ lies outside the unit circle. Then
\[
    X_t-\mu=\frac{\theta(B)}{\phi(B)}\varepsilon_t
           =\sum_{j=0}^{\infty}\psi_j\varepsilon_{t-j},
    \qquad \sum_{j=0}^{\infty}|\psi_j|<\infty.
\]
Its spectral density is the rational function
\[
    f_X(\omega)
    =\frac{\sigma^2}{2\pi}
      \frac{|\theta(e^{-\ii\omega})|^2}{|\phi(e^{-\ii\omega})|^2}.
\]
Poles created by the AR polynomial produce persistent or oscillatory modes;
zeros created by the MA polynomial suppress selected frequencies. This is the
frequency-domain meaning of an ARMA model.

\begin{thm}[Wold decomposition]
Let $\{X_t\}$ be a zero-mean, weakly stationary, purely nondeterministic process
with finite variance. Then
\[
    X_t=\sum_{j=0}^{\infty}\psi_j\varepsilon_{t-j},
    \qquad \psi_0=1,\qquad \sum_{j=0}^{\infty}\psi_j^2<\infty,
\]
where $\varepsilon_t$ is the one-step innovation: the part of $X_t$ that cannot
be linearly predicted from its past.
\end{thm}

``Purely nondeterministic'' rules out a nonzero component perfectly predictable
from the infinite past. Wold's theorem explains why linear filters of innovations
are fundamental: they are not merely a convenient parametric guess. ARMA models
replace the infinite filter $\sum_j\psi_jz^j$ by the parsimonious rational
approximation $\theta(z)/\phi(z)$.

The ACF and partial ACF (PACF) provide a useful first diagnostic. The PACF at lag
$h$ measures the remaining linear association between $X_t$ and $X_{t-h}$ after
accounting for the intermediate lags. In ideal population models,
\[
\begin{array}{c|ccc}
 & \operatorname{AR}(p) & \operatorname{MA}(q) & \operatorname{ARMA}(p,q)\\
\hline
\text{ACF}  & \text{tails off} & \text{cuts off after }q & \text{tails off}\\
\text{PACF} & \text{cuts off after }p & \text{tails off} & \text{tails off}
\end{array}
\]
This pattern suggests candidate orders; it does not prove that a model is
correct. After fitting, the estimated innovations should resemble white noise.
Visible autocorrelation in the residuals means that predictable structure remains.
Among models with adequate residuals, criteria such as AIC or BIC trade improved
fit against unnecessary order.

\subsubsection{Nonstationarity and hidden state}
ARMA models describe stationary series. For a series whose differences are
stationary, an $\operatorname{ARIMA}(p,d,q)$ model is
\[
    \phi(B)(1-B)^dX_t=\theta(B)\varepsilon_t.
\]
The random walk is $\operatorname{ARIMA}(0,1,0)$. Seasonal differencing replaces
$1-B$ by $1-B^s$ when a pattern repeats every $s$ observations. Differencing is
not a ritual: it asserts that changes are stable even when levels are not. Too
much differencing injects artificial dependence and increases forecast variance,
so one should use the smallest $d$ that makes a stationary description plausible.

Another viewpoint separates an unobserved state from noisy measurements:
\[
\begin{aligned}
    Z_{t+1}&=AZ_t+\eta_{t+1}, &&\text{state evolution},\\
    X_t&=CZ_t+\varepsilon_t, &&\text{observation}.
\end{aligned}
\]
In a linear Gaussian state space model, the Kalman filter alternates between
predicting $Z_t$ from the previous state and correcting that prediction using the
new forecast error $X_t-C\widehat{Z}_{t\mid t-1}$. The model distinguishes
uncertainty about a changing signal from measurement noise. ARMA models admit
state space representations, but the state space language also naturally handles
missing observations, time-varying latent trends, and multivariate signals.

\subsubsection{CNNs and RNNs as time-series models}
Classical models make their memory explicit and linear. Neural models can learn
nonlinear summaries of the past, but the same design question remains: what part
of $\mathcal{F}_t$ should be retained?

A one-dimensional \textbf{causal convolutional network} begins with filters such as
\[
    H_t=\sigma\!\left(b+\sum_{j=0}^{k-1}W_jX_{t-j}\right).
\]
With the identity activation, this is simply a finite linear filter. Nonlinear
activations and stacked filters learn local motifs; dilation allows a large time
window without an equally deep network. Shared weights encode the belief that a
pattern has the same meaning wherever it appears in time.

A \textbf{recurrent neural network} instead updates a learned state,
\[
    H_t=\sigma(UH_{t-1}+VX_t+b),
    \qquad
    \widehat{X}_{t+h\mid t}=g(H_t).
\]
The hidden state is a nonlinear, data-adaptive analogue of a state space model.
If the activation is the identity and the powers of $A$ decay, then
$H_t$ becomes an infinite linear filter of past observations. Thus CNNs resemble
finite impulse response filters, while stable RNNs resemble infinite impulse
response or state space models.

\begin{tabular}{>{\raggedright\arraybackslash}p{0.16\textwidth}
                >{\raggedright\arraybackslash}p{0.25\textwidth}
                >{\raggedright\arraybackslash}p{0.25\textwidth}
                >{\raggedright\arraybackslash}p{0.22\textwidth}}
\toprule
Model & Memory & Main advantage & Main caution\\
\midrule
ARMA & Explicit linear recursion and shocks & Interpretable, data-efficient, probabilistic forecasts & Requires approximately stationary linear dynamics\\

\bottomrule
\end{tabular}
\end{center}

CNNs and RNNs are useful examples, not automatic replacements for ARMA. A flexible
model can fit dependence that is too weak to estimate reliably from a single
series. It should therefore be compared with simple forecasts, evaluated only on
future observations, and judged by calibration as well as point accuracy. The
essential question is unchanged: after conditioning on the model's summary of the
past, is there any predictable structure left in the forecast errors?

\subsubsection*{(A) Leverage Scores}
\phantomsection
\addcontentsline{toc}{subsubsection}{(A) Leverage Scores}
\label{ex:leverage-scores}

Observations at different locations in predictor space can play different roles
in a least-squares fit. If we perturb a single response $y_i$, how much does its
fitted value $\hat y_i$ change? Understanding this sensitivity helps us assess
how strongly an observation can pull the fitted model toward itself. Leverage
scores connect this question to the geometry of the design matrix.

Let $\bX\in\mathbb R^{N\times P}$ have full column rank, with $i$-th row
$\bx_i^\top$. Consider the ordinary least-squares estimator and fitted responses
\[
    \hat{\boldsymbol\beta}
    =(\bX^\top\bX)^{-1}\bX^\top\bY,
    \qquad
    \hat{\bY}=\bX\hat{\boldsymbol\beta}.
\]
Define the \textbf{hat matrix}
\[
    \mathbf H=\bX(\bX^\top\bX)^{-1}\bX^\top.
\]
Its diagonal entry $h_{ii}$ is called the \textbf{leverage score} of observation $i$.

\begin{enumerate}[label=\textcolor{AccentInk}{\sffamily\bfseries A\arabic*.},
                  ref=A\arabic*,leftmargin=2.65em,labelsep=0.65em,itemsep=1em]
\item Show that
\[
    h_{ii}=\bx_i^\top(\bX^\top\bX)^{-1}\bx_i,
\]
and prove that $0\le h_{ii}\le 1$.

\item Holding $\bX$ and all other responses fixed, prove that
\[
    \frac{\partial\hat y_i}{\partial y_i}=h_{ii}.
\]
Interpret this identity: when $y_i$ is increased by a small amount, how does
$\hat y_i$ change? What does a leverage score close to $1$ mean?

\item \textbf{(Leave-one-out regression)}
Let $\hat{\boldsymbol\beta}_{[-i]}$ denote the least-squares estimator obtained
after removing observation $i$:
\[
    \hat{\boldsymbol\beta}_{[-i]}
    =\operatorname*{argmin}_{\boldsymbol\beta\in\mathbb R^P}
    \sum_{k\ne i}(y_k-\bx_k^\top\boldsymbol\beta)^2.
\]
For A3--A4, assume that the design matrix remains of full column rank after
removing observation $i$. Writing
$\hat\epsilon_i=y_i-\bx_i^\top\hat{\boldsymbol\beta}$, prove that
\[
    \hat{\boldsymbol\beta}_{[-i]}
    =\hat{\boldsymbol\beta}
    -\frac{(\bX^\top\bX)^{-1}\bx_i}{1-h_{ii}}\,\hat\epsilon_i.
\]
Discuss the roles of the leverage score and the training residual in this
expression. Does a large leverage score alone imply a large change in the
estimated coefficients?

\item \textbf{(Residuals)}
Define the leave-one-out prediction residual
\[
    \hat\epsilon_{[-i]}:=y_i-\bx_i^\top\hat{\boldsymbol\beta}_{[-i]}.
\]
Using A3, show that
\[
    \hat\epsilon_{[-i]}=\frac{\hat\epsilon_i}{1-h_{ii}}.
\]
Explain why a small training residual need not imply a small leave-one-out
prediction error. How does the leverage score affect the discrepancy between
these two residuals?

\newpage
\item \textbf{(Variance inflation factor)}
We now turn from the role of individual observations to the relationships among
predictors. Assume
\[
    \bY=\bX\boldsymbol\beta+\boldsymbol\epsilon,
    \qquad
    \mathbb E[\boldsymbol\epsilon\mid\bX]=\mathbf0,
    \qquad
    \operatorname{Cov}(\boldsymbol\epsilon\mid\bX)=\sigma^2\bI_N.
\]
Derive $\operatorname{Cov}(\hat{\boldsymbol\beta}\mid\bX)$.

Suppose that $\bX$ includes an intercept. For a non-intercept predictor $j$, let
$R_j^2$ be the coefficient of determination obtained by regressing that predictor
on all remaining predictors, including the intercept. Show that
\[
    \operatorname{Var}(\hat\beta_j\mid\bX)
    =\frac{\sigma^2}{\sum_{i=1}^N(x_{ij}-\bar x_j)^2}
     \cdot\frac{1}{1-R_j^2},
    \qquad
    \bar x_j=\frac1N\sum_{i=1}^N x_{ij}.
\]
The quantity
\[
    \operatorname{VIF}_j:=\frac{1}{1-R_j^2}
\]
is called the \textbf{variance inflation factor}. Explain its interpretation by
comparing with $R_j^2=0$, holding $\sigma^2$ and the variation of predictor $j$
fixed. What happens as $R_j^2\to1$, and why does near linear dependence among
predictors make individual coefficients difficult to estimate?
\end{enumerate}

\subsubsection*{(B) AIC and BIC}
\phantomsection
\addcontentsline{toc}{subsubsection}{(B) AIC and BIC}
\label{ex:aic-bic}

Adding predictors can reduce training error, but how much improvement justifies
a more complicated model? We explore this question through leave-one-out
prediction and through averaging the likelihood over a prior.

Consider candidate Gaussian linear models
\[
    M_p:\quad \bY\mid\boldsymbol\beta,\sigma^2
    \sim\mathcal N(\bX_p\boldsymbol\beta,\sigma^2\bI_N),
    \qquad \boldsymbol\beta\in\mathbb R^p,
\]
where $\bX_p\in\mathbb R^{N\times p}$ is fixed and has full column rank.
All models use the same $N$ responses; $p<N$ counts all regression coefficients,
including an intercept if present, and $\sigma^2$ is unknown. Write
$\operatorname{RSS}_p=\sum_{i=1}^N\hat\epsilon_i^2$ and let
$\ell_p(\boldsymbol\beta,\sigma^2)$ denote the log-likelihood. Residuals and
leverage scores refer to $M_p$, and conditioning on $\bX_p$ is suppressed.

\begin{enumerate}[label=\textcolor{AccentInk}{\sffamily\bfseries B\arabic*.},
                  ref=B\arabic*,leftmargin=2.65em,labelsep=0.65em,itemsep=1em]
\item Assume that deleting any observation preserves full column rank.
Using A4, express
\[
    \log\!\left(\sum_{i=1}^N\hat\epsilon_{[-i]}^2\right)
\]
in terms of the full-sample residuals and leverage scores. Prove that
$\sum_{i=1}^N h_{ii}=p$.

\item Suppose that $h_{ii}=p/N$ for every $i$. Simplify your expression in B1
and, for $p/N\to0$, expand
\[
    N\log\!\left(\frac1N\sum_{i=1}^N\hat\epsilon_{[-i]}^2\right)
\]
through the first-order correction to $N\log(\operatorname{RSS}_p/N)$.
What penalty for model complexity appears? Bound the remainder.
Why is $\sum_i h_{ii}=p$ alone insufficient for this calculation when the
leverage scores are unequal?

\item Calculate the maximum-likelihood estimates and the maximized Gaussian
log-likelihood. Rewrite the leading criterion from B2 using this log-likelihood
and the number of estimated parameters. Identify the result as
\textbf{Akaike's information criterion (AIC)}~\cite{akaike1974newlook}.
Why does counting the unknown variance add a term common to all models?

\item Choose a proper prior on the coefficients and noise variance. For
example, take
\[
    \boldsymbol\beta\mid\sigma^2,M_p
    \sim\mathcal N(\mathbf0,\tau^2\sigma^2\bI_p),
    \qquad
    \sigma^2\mid M_p\sim\operatorname{Inv\text{-}Gamma}(a,b),
\]
with $a,b,\tau>0$ fixed independently of $N$ and of the observed responses.
Here $\pi_{\sigma^2}(s)=b^a s^{-a-1}\exp(-b/s)/\Gamma(a)$ for $s>0$.
Complete the square to calculate
\[
    p(\bY\mid s,M_p)
    =\int_{\mathbb R^p}p(\bY\mid\boldsymbol\beta,s,M_p)
      \pi_{\boldsymbol\beta}(\boldsymbol\beta\mid s,M_p)
      \,\mathrm d\boldsymbol\beta.
\]
Keep all normalizing constants that depend on $p$.

\item Integrate the expression in B4 over $s$ to obtain
$\log p(\bY\mid M_p)$. For fixed $p$, suppose that
\[
    \frac1N\bX_p^\top\bX_p\longrightarrow Q_p\succ0,
    \qquad \hat{\boldsymbol\beta}_p=O_{\mathbb P}(1),
    \qquad \frac{\operatorname{RSS}_p}{N}
       \xrightarrow{\mathbb P}c_p>0.
\]
Using Stirling's formula, expand the log marginal likelihood around the maximized
log-likelihood, with remainder $O_{\mathbb P}(1)$. Determine the coefficient of
$\log N$ and explain where it comes from.

\item Retain the leading terms of $-2\log p(\bY\mid M_p)$ and remove terms
common to all models. Write the resulting model-selection criterion in terms of
$\operatorname{RSS}_p$, $N$, and $p$. Identify it as the
\textbf{Bayesian information criterion (BIC)}~\cite{schwarz1978dimension}.
Which terms of the marginal-likelihood expansion depend on the prior?
Compare the complexity penalty and motivation with the criterion in B3.
\end{enumerate}

\subsubsection*{(C) Heteroscedasticity}
\phantomsection
\addcontentsline{toc}{subsubsection}{(C) Heteroscedasticity}
\label{ex:heteroscedasticity}

The conditional variance of a response can change with its predictors. For
binary and count data, this variation arises naturally from the response
distribution. How do these unequal variances enter the curvature of the
log-likelihood, and how can we estimate that curvature from a fitted model?

Let $\bX\in\mathbb R^{N\times P}$ have full column rank, with rows
$\bx_i^\top$. Conditional on $\bX$, suppose that the responses are independent
and follow a regular exponential family with unit dispersion:
\[
    f(y_i;\eta_i)=\exp\!\bigl\{y_i\eta_i-b(\eta_i)+c(y_i)\bigr\},
    \qquad \eta_i=\bx_i^\top\boldsymbol\beta.
\]
Setting the natural parameter equal to the linear predictor is the
\textbf{canonical link} specification. Write $\ell(\boldsymbol\beta)$ for the
log-likelihood, and assume that a finite interior maximum-likelihood estimate
$\hat{\boldsymbol\beta}$ exists.

\begin{enumerate}[label=\textcolor{AccentInk}{\sffamily\bfseries C\arabic*.},
                  ref=C\arabic*,leftmargin=2.65em,labelsep=0.65em,itemsep=1em]
\item \textbf{(Estimating the Hessian)}
Express $\mathbb E[Y_i\mid\bX]$ and $\operatorname{Var}(Y_i\mid\bX)$ in terms
of derivatives of $b$. Derive the score vector and prove that
\[
    \nabla_{\boldsymbol\beta}^2\ell(\boldsymbol\beta)
    =-\bX^\top\mathbf W(\boldsymbol\beta)\bX,
    \qquad
    \mathbf W(\boldsymbol\beta)
    =\operatorname{Cov}_{\boldsymbol\beta}(\bY\mid\bX).
\]
Construct plug-in estimates of $\mathbf W$ and the Hessian using
$\hat{\boldsymbol\beta}$. Under correct specification and standard regularity
conditions, derive the corresponding large-sample covariance estimator for
$\hat{\boldsymbol\beta}$.

\item \textbf{(Logistic regression)}
Suppose that
\[
    Y_i\mid\bX\sim\operatorname{Bernoulli}(\pi_i),
    \qquad \log\!\left(\frac{\pi_i}{1-\pi_i}\right)
       =\bx_i^\top\boldsymbol\beta.
\]
Identify $b$, and calculate $\mathbf W(\boldsymbol\beta)$ and the Hessian.
Write their fitted versions in terms of
$\hat\pi_i=(1+\exp(-\bx_i^\top\hat{\boldsymbol\beta}))^{-1}$.
For fixed $\bx_i$, at which value of $\pi_i$ does observation $i$ contribute
the most information about $\boldsymbol\beta$? What happens as $\pi_i$
approaches $0$ or $1$?

\item \textbf{(Poisson regression)}
Suppose that
\[
    Y_i\mid\bX\sim\operatorname{Poisson}(\mu_i),
    \qquad \log\mu_i=\bx_i^\top\boldsymbol\beta.
\]
Identify $b$, and calculate $\mathbf W(\boldsymbol\beta)$ and the Hessian.
Write their fitted versions in terms of
$\hat\mu_i=\exp(\bx_i^\top\hat{\boldsymbol\beta})$.
For fixed $\bx_i$, how does observation $i$'s contribution to the information
about $\boldsymbol\beta$ change as $\mu_i$ increases? Explain why unequal
conditional variances can arise even when this model is correctly specified.
\end{enumerate}

\subsubsection*{(D) Contingency Tables}
\phantomsection
\addcontentsline{toc}{subsubsection}{(D) Contingency Tables}
\label{ex:contingency-tables}

Do different groups have the same distribution across a set of categories?
A contingency table records the relevant counts, but the sampling design
determines which totals are fixed and which are random. We will connect two
sampling schemes and discover how likelihood comparisons and local curvature
lead to two familiar tests of association.

Let $Y_{jk}$ be the count in cell $(j,k)$ of a $J\times K$ table, with
$J,K\ge2$. The observed table $y=(y_{jk})$ and its margins are arranged as
follows:
\begin{center}
\begingroup
\setlength{\tabcolsep}{12pt}
\renewcommand{\arraystretch}{1.22}
\begin{tabular}{lccccc>{\columncolor{AccentWash}}c}
\toprule
\textsf{Group} & \multicolumn{5}{c}{\textsf{Category}} & \textsf{Row total}\\
\cmidrule(lr){2-6}
 & $1$ & $\cdots$ & $k$ & $\cdots$ & $K$ & \\
\midrule
$1$ & $y_{11}$ & $\cdots$ & $y_{1k}$ & $\cdots$ & $y_{1K}$ & $n_1=y_{1+}$\\
$\vdots$ & $\vdots$ & & $\vdots$ & & $\vdots$ & $\vdots$\\
$j$ & $y_{j1}$ & $\cdots$ & \cellcolor{AccentWash}$\textcolor{AccentInk}{y_{jk}}$
    & $\cdots$ & $y_{jK}$ & $n_j=y_{j+}$\\
$\vdots$ & $\vdots$ & & $\vdots$ & & $\vdots$ & $\vdots$\\
$J$ & $y_{J1}$ & $\cdots$ & $y_{Jk}$ & $\cdots$ & $y_{JK}$ & $n_J=y_{J+}$\\
\midrule
\rowcolor{AccentWash}
\textsf{Column total} & $y_{+1}$ & $\cdots$ & $y_{+k}$ & $\cdots$ & $y_{+K}$
    & $N=y_{++}$\\
\bottomrule
\end{tabular}
\endgroup
\end{center}
Here $n_j=y_{j+}=\sum_{k=1}^K y_{jk}$,
$y_{+k}=\sum_{j=1}^J y_{jk}$, and $N=y_{++}=\sum_{j,k}y_{jk}$.
Assume that all observed row and column totals are positive. Individual cells
may be zero; use the convention $0\log(0/u)=0$ for $u>0$, and allow saturated
maximum-likelihood fits on the boundary.

\begin{enumerate}[label=\textcolor{AccentInk}{\sffamily\bfseries D\arabic*.},
                  ref=D\arabic*,leftmargin=2.65em,labelsep=0.65em,itemsep=1em]
\item \textbf{(Two sampling schemes)}
Under \emph{Poisson sampling}, the cell counts are independent with
$Y_{jk}\sim\operatorname{Poisson}(\mu_{jk})$.
Under \emph{product multinomial sampling}, the rows are independent with
\[
    (Y_{j1},\ldots,Y_{jK})
    \sim\operatorname{Multinomial}(n_j;p_{j1},\ldots,p_{jK}),
    \qquad \sum_{k=1}^K p_{jk}=1,
\]
where each $n_j$ is fixed by design. Write both likelihoods. Which totals are
random in each model? Are the cell counts within a row independent under the
second model?

\item \textbf{(Conditioning and profiling)}
In the Poisson model, write $\mu_{jk}=a_jp_{jk}$ with $a_j>0$ and
$\sum_kp_{jk}=1$. Factor the joint likelihood into a likelihood for the row
totals and a conditional likelihood for the counts given those totals.
Identify the conditional model. Maximize over $a_1,\ldots,a_J$ and show that
the resulting profile likelihood for $p=(p_{jk})$ is proportional to the
product multinomial likelihood, with a factor independent of $p$.

\item \textbf{(No association)}
Under $H_0:p_{jk}=q_k$ for every $j$, with $\sum_kq_k=1$, show that the
Poisson log-means satisfy $\log\mu_{jk}=\alpha_j+\beta_k$.
Explain the connection to independence of the row and column categories.
Find the saturated and null fits under each sampling scheme. Express the
null fitted counts $\widetilde\mu_{jk}$ (Poisson) and $n_j\widetilde p_{jk}$
(product multinomial) using the observed margins, and show that they agree.

\item \textbf{(Comparing likelihoods)}
For each sampling scheme, calculate
\[
    G^2=2\left\{\sup_{\mathrm{saturated}}\ell
                    -\sup_{H_0}\ell\right\},
\]
where the saturated model allows a separate parameter for each cell, subject
only to the probability normalizations when applicable. Simplify $G^2$ in
terms of $y_{jk}$ and $\widetilde\mu_{jk}$. Why do the linear terms in the
Poisson expression cancel? Use D2 to explain why the two sampling schemes
give the same statistic. Identify the result as the
\textbf{likelihood-ratio deviance statistic}.

\item \textbf{(A local calculation)}
Parameterize the saturated Poisson model by
$\theta_{jk}=\log\mu_{jk}$, and collect these parameters in a vector
$\boldsymbol\theta$. Using C3, calculate its score
$U(\boldsymbol\theta)$ and expected Fisher information
$I(\boldsymbol\theta)$. At the null fit
$\widetilde\theta_{jk}=\log\widetilde\mu_{jk}$, simplify the score statistic
\[
    X^2=U(\widetilde{\boldsymbol\theta})^\top
        I(\widetilde{\boldsymbol\theta})^{-1}
        U(\widetilde{\boldsymbol\theta}).
\]
Identify the result as \textbf{Pearson's chi-square statistic}.
Why can the full-model score be nonzero even though the scores for the null
model's parameters vanish at their fitted values? Using the factorization
in D2, show that the product multinomial score test gives the same statistic.

\item \textbf{(Counting the remaining directions)}
For each sampling scheme, count the dimensions of the saturated and null
models. Explain why the dimension differences agree. Show that the fitted
residuals $y_{jk}-\widetilde\mu_{jk}$ have zero row sums and zero column sums;
how many independent constraints does this impose?

Under $H_0$, keep $J,K$ fixed and take $q_k>0$. For product multinomial
sampling, let $N\to\infty$ with $n_j/N\to r_j>0$; for Poisson sampling,
take $a_j=t r_j$ with $t\to\infty$, $r_j>0$, and $\sum_jr_j=1$.
Use likelihood theory to obtain the limiting null distributions of $G^2$
and $X^2$, including their degrees of freedom. Explain why the number of
cells alone does not determine those degrees of freedom.

\item \textbf{(Two views of the same local discrepancy)}
Under the null and the asymptotic conditions in D6, expand the expression
for $G^2$ from D4 around $y_{jk}=\widetilde\mu_{jk}$. Use the margin
identities to remove the linear terms and prove that
\[
    G^2-X^2=o_{\mathbb P}(1).
\]
What does this reveal about the relation between likelihood-ratio and score
tests? Are the two statistics necessarily equal for a finite observed table?
\end{enumerate}
